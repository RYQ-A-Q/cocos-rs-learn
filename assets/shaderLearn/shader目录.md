### 1. ColorAdjust — 全图色彩调整

| 项目 | 内容 |
|------|------|
| **文件位置** | [20261016/ColorAdjust.effect](20261016/ColorAdjust.effect) |
| **Technique 名称** | `color-adjust` |
| **材质文件** | [20261016/ColorAdjust.mtl](20261016/ColorAdjust.mtl) |
| **功能描述** | 对精灵贴图进行全图色彩调整，支持亮度、饱和度、对比度、色相偏移、柔和度（柔化/锐化）以及效果强度控制 |

|--------|--------|------|--------|------|
| `brightness` | 亮度 | [-100, 100] | 50 | 0 为原始亮度，正数增亮 |
| `saturation` | 饱和度 | [-100, 100] | 50 | 0 为原始饱和度，正数增强 |
| `contrast` | 对比度 | [-100, 100] | 50 | 0 为原始对比度，正数增强 |
| `softness` | 柔和度 | [-100, 100] | 1 | 正数柔化（四方向邻域混合），负数锐化 |
| `hue` | 色相偏移 | [-100, 100] | 50 | 0 为原始色相，正负数向不同方向偏移 |
| `effectStrength` | 效果强度 | [-100, 100] | 100 | 0 使用原图，100 使用完整调整效果 |

## 三、扫描线效果类

### 5. ScanLine — 彩色扫描线

| 项目 | 内容 |
|------|------|
| **文件位置** | [20261016/ScanLine.effect](20261016/ScanLine.effect) |
| **Technique 名称** | `scan-line` |
| **材质文件** | [20261016/ScanLine.mtl](20261016/ScanLine.mtl) |
| **功能描述** | 在精灵贴图上叠加一条可移动的彩色扫描线。扫描线沿指定方向匀速运动，支持多种亮度样式（中间亮两侧渐隐 / 均匀亮带 / 柔和亮带），颜色、宽度、速度、透明度均可调节。使用 `cc_time` 驱动动画，适合科技感、扫描特效等场景 |

**可调属性：**

| 属性名 | 显示名 | 范围 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| `scanColor` | 扫描颜色 | 颜色 | [0.2, 0.8, 1.0, 1.0] | 扫描线的 RGBA 颜色 |
| `scanDirection` | 扫描方向（度） | 任意 | -30 | 扫描线的角度方向（角度制） |
| `scanOffset` | 扫描位置偏移 | 任意 | 0 | 手动偏移扫描线的起始位置 |
| `scanSpeed` | 扫描速度 | 任意 | 0.5 | 扫描线移动速度，越大越快 |
| `scanWidth` | 扫描宽度 | 任意 | 0.08 | 扫描线的宽度（UV 空间） |
| `scanSoftness` | 边缘柔和度 | 任意 | 0.025 | 扫描线边缘的柔和过渡程度 |
| `scanBrightness` | 扫描亮度 | 任意 | 1.5 | 扫描线区域的亮度倍增 |
| `scanAlpha` | 扫描透明度 | 任意 | 1.0 | 扫描线的整体透明度 |
| `scanStyle` | 扫描样式 | [0, 2] | 0 | 0=中间亮两侧渐隐，1=均匀亮带，2=中间亮边缘更柔和 |

**核心算法：**
- 将 UV 投影到扫描方向的法向量上，计算当前像素与扫描线的带符号距离
- 通过 `cc_time` 驱动扫描线沿法向量方向匀速运动
- 使用 `smoothstep` 实现扫描线边缘的柔和过渡

### 6. ScanLineLight — 高亮扫描光

| 项目 | 内容 |
|------|------|
| **文件位置** | [20261016/ScanLineLight.effect](20261016/ScanLineLight.effect) |
| **Technique 名称** | `scan-line-light` |
| **材质文件** | [20261016/ScanLineLight.mtl](20261016/ScanLineLight.mtl) |
| **功能描述** | 与 ScanLine 技术方案相同，但**不引入自定义颜色**，而是直接增强扫描区域的原图颜色（`rgb *= 1 + strength`）。效果更自然，适合作为"高亮扫光"、"光泽划过"等需要保留原始贴图颜色的场景 |

**可调属性：**

| 属性名 | 显示名 | 范围 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| `scanDirection` | 扫描方向（度） | 任意 | -30 | 扫描线的角度方向（角度制） |
| `scanOffset` | 扫描位置偏移 | 任意 | 0 | 手动偏移扫描线的起始位置 |
| `scanSpeed` | 扫描速度 | 任意 | 0.5 | 扫描线移动速度，越大越快 |
| `scanWidth` | 扫描宽度 | 任意 | 0.08 | 扫描线的宽度（UV 空间） |
| `scanSoftness` | 边缘柔和度 | 任意 | 0.025 | 扫描线边缘的柔和过渡程度 |
| `scanBrightness` | 亮度增强 | 任意 | 1.0 | 扫描区域原图亮度的增强倍率 |
| `scanAlpha` | 扫描强度 | 任意 | 1.0 | 扫描效果的整体强度 |
| `scanStyle` | 扫描样式 | [0, 2] | 0 | 0=中间亮两侧渐隐，1=均匀亮带，2=柔和亮带 |

**与 ScanLine 的区别：**
- 无 `scanColor` 属性 — 不叠加自定义颜色
- 直接对原图 RGB 做乘法增强，而非叠加混色
- 不修改原图 Alpha 通道
- 效果更自然，适合「光泽划过」「高亮扫光」等效果

## 四、破碎/特效类

### 7. Shatter — 破碎飞散

| 项目 | 内容 |
|------|------|
| **文件位置** | [20261016/Shatter.effect](20261016/Shatter.effect) |
| **Technique 名称** | `shatter` |
| **材质文件** | [20261016/Shatter.mtl](20261016/Shatter.mtl) |
| **配套脚本** | [20261016/sc/ShatterMesh.ts](20261016/sc/ShatterMesh.ts) — 生成 Voronoi 多边形网格，顶点颜色编码碎片中心和随机值 |
| **功能描述** | 基于 **Voronoi 图** 的破碎飞散效果。随着 `progress`（0→1）推进，贴图被分割为多个多边形碎片，碎片从画面中心向外飞散、旋转、产生裂缝间隙，并最终淡出消失。适合碎屏特效、卡片破碎、死亡消失等场景 |

**可调属性：**

| 属性名 | 显示名 | 范围 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| `progress` | 破碎进度 | [0, 1] | 0 | 0 完整原图，1 完全破碎飞散消失 |
| `fragmentCount` | 碎片数量 | [4, 30] | 12 | Voronoi 种子点数，值越大碎片越多越细碎 |
| `flyDistance` | 飞散距离 | [0, 0.6] | 0.25 | 碎片从中心向外飞散的最大距离（UV 空间） |
| `fragmentSize` | 碎片大小 | [0.5, 1.5] | 1.0 | 碎片缩放系数，<1 收缩，>1 放大 |
| `rotationSpeed` | 旋转强度 | [0, 5] | 1.0 | 碎片绕自身中心旋转的速度/角度 |
| `gapWidth` | 裂缝宽度 | [0, 0.03] | 0.006 | 碎片之间裂缝的宽度 |
| `fadeSpeed` | 消失速度 | [0.1, 1.0] | 0.7 | 碎片开始淡出的进度阈值，值越小越早开始消失 |

**核心算法：**
- **Voronoi 划分**：通过 `hash22` 在 3×3 邻域搜索最近和次近种子点，将画面分割为不规则多边形
- **飞散与旋转**：每个碎片从中心沿径向（叠加随机扰动）向外位移，同时绕自身中心旋转
- **裂缝生成**：利用 Voronoi 相邻中心距离差（`secondNearest - nearest`）计算裂缝宽度
- **随机淡出**：每个碎片带有独立的随机值，淡出起始点各不相同，实现自然的异步消失
- **配套网格脚本**：`ShatterMesh.ts` 通过 Voronoi 划分生成实际的多边形 Mesh，在顶点颜色中编码碎片中心坐标和随机值

## 五、基础渲染类

### 8. UnitySpriteDefault — Unity Sprite 默认着色器

| 项目 | 内容 |
|------|------|
| **文件位置** | [20261016/UnitySpriteDefault.effect](20261016/UnitySpriteDefault.effect) |
| **Technique 名称** | `unity-sprite-default` |
| **材质文件** | [20261016/UnitySpriteDefault.mtl](20261016/UnitySpriteDefault.mtl) |
| **功能描述** | 模拟 Unity `Sprites/Default` 着色器行为的基础精灵渲染器。实现预乘 Alpha（Premultiplied Alpha）处理，确保与 Unity 项目的渲染结果一致 |

**特性：**
- 基础精灵纹理采样
- 顶点颜色支持（`USE_LOCAL` 宏）
- 预乘 Alpha：`o.rgb *= o.a`，对齐 Unity 的混合模式（`blendSrc: one, blendDst: one_minus_src_alpha`）
- 无可调属性，渲染行为固定

## 六、对比总结

| Shader | 类别 | 核心用途 | 特有功能 |
|--------|------|----------|----------|
| **ColorAdjust** | 色彩调整 | 全图色彩后处理 | 亮度/饱和度/对比度/色相/柔和度，效果强度混合 |
| **ColorAdjust-item1** | 色彩调整 | 物品独立调色 | 继承 ColorAdjust 全部功能 + 物品遮罩 + 边缘保护 |
| **PixelArt** | 像素艺术 | 复古像素风格化 | 像素网格/色阶量化/边缘强化/暗部强化，偏硬朗复古 |
| **PixelArt-1** | 像素艺术 | 插画像素风格化 | 同 PixelArt 方案但参数调优，偏柔和插画 |
| **ScanLine** | 扫描线效果 | 彩色扫描线叠加 | 可选颜色的移动扫描线，3 种亮度样式，cc_time 驱动 |
| **ScanLineLight** | 扫描线效果 | 高亮扫光 | 不叠加颜色，直接增强原图亮度，效果更自然 |
| **Shatter** | 破碎/特效 | Voronoi 破碎飞散 | 多边形碎片/飞散旋转/裂缝/异步淡出，配套 Mesh 脚本 |
| **UnitySpriteDefault** | 基础渲染 | Unity 兼容渲染 | 预乘 Alpha 处理，对齐 Unity Sprites/Default |
